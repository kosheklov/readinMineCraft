# Два упражнения на понимание прочитанного

Отдельные адреса `/ru/otgaday-po-opisaniyu/` и `/ru/pravda-ili-net/`, по 10 заданий. Точки входа с главной пока не добавляются по указанию владельца. Обе страницы noindex.

Вдохновение: открытые разделы LogicLike https://logiclike.com/math-logic/zagadki-na-logiku/detskie и https://logiclike.com/math-logic/pravda-i-lozh . Использованы идеи форматов; все условия и наборы ответов написаны самостоятельно. Закрытый кабинет не использован.

Первый набор — описание и выбор слова (M2), второй — два предложения и проверка буквального утверждения (M4). Аудитория: читающие дети 5–7 лет с возможной помощью взрослого. Это практика, не диагностика. Нет озвучки, новых аналитических событий или записи результатов в карту навыков. Методическая апробация с детьми ещё не проводилась.

Один общий runtime для двух наборов. Используются стили, шрифт, сундук, Minecraft-атлас и шесть тем существующего `/ru/naydi-lishnee/`. Тема сохраняется в общем ключе `rck.rewardTheme.v1`. Правильный ответ или разбор после двух ошибок → отдельный сундук → отдельный приз → следующее задание. Все десять призов уникальны, двойная выдача блокируется. Подсказки и разбор видны в итогах, при перезапуске прохождение сбрасывается.

Проверки: `node --test tests/reading-games.test.mjs tests/odd-word.test.mjs`, `node tests/run-tests.mjs`. В браузере пройдены оба набора целиком, проверены ошибка, подсказка, показ ответа и коллекции. Ширины 390px и desktop; физических мобильных устройств не было.
