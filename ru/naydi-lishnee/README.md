# Найди лишнее слово

Отдельная страница `/ru/naydi-lishnee/`, без входящих ссылок с главной. 10 вопросов × 3 слова = 30 уникальных слов. Собственный набор по мотивам механики смыслового выбора; тексты и иллюстрации LogicLike не копировались.

Аудитория — дети 5–7 лет с помощью взрослого при чтении условия. Разные длины слов и категории: это практический набор, не адаптивная диагностика и не оценка техники чтения. Методическая проверка и наблюдение с детьми ещё не проведены.

Первый вопрос предлагает озвучку трёх слов голосом Marina. Все записи скопированы без изменений из действующего `marina-owner-pilot-v1` (approved_for_pilot); новые записи не синтезировались. Остальные девять вопросов текстовые, что явно указано до старта. Браузерный TTS не применяется. Использование записей в новом упражнении не означает методического одобрения нового набора.

Результаты живут в памяти страницы. Нет записи в карту навыков, персональных данных, новых аналитических запросов ; изображения тематических призов загружаются с readingcraftkids.com. Озвучка считается помощью только после начала воспроизведения. Ошибка звука позволяет продолжить, сохранив попытки и ранее использованную помощь. При повторе показано ограничение знакомого набора.

Публиковать только эту папку: HTML, CSS, модули, изображения, шрифт и три WAV. Существующие страницы, навигация, workflow, CNAME и discovery-файлы не меняются. `noindex` стоит до отдельного решения о точке входа и индексации.

После каждого завершённого задания открывается отдельный экран «Спасибо! Ты заработал сундук!». Нажатие «Открыть сундук» переводит на отдельный экран приза; только затем доступно следующее задание. Цвета взяты из действующего основного игрового экрана: тёмный фон и синие кнопки. Ошибку обозначают красная рамка, подпись и пояснение.

Перед стартом доступны шесть тем: Minecraft, Динозавры, Космос, Единороги, Феи, Цветочный сад. Выбор сохраняется в общем с основным тренажёром ключе `rck.rewardTheme.v1`. В прохождении выдаются десять разных призов выбранной темы, включая задания с помощью. Повторное открытие не выдаёт второй приз. Коллекция сбрасывается при новом прохождении. `themes.mjs` содержит имена и координаты изображений из основного тренажёра; тематические атласы используются с основного домена. `chest.png` и `prizes.png` — неизменённые исходные изображения тренажёра.

Проверки: `node --test tests/odd-word.test.mjs` и `node tests/run-tests.mjs`.
