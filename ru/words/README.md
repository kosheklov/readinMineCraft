# Русские слова дня

Уровень 4–5 лет пересобран 2026-10-01 после обратной связи родителя: 69 знакомых
слов без стечений согласных, ь и ъ. Сначала в занятии идут два открытых слога,
затем короткие односложные слова, затем три простых слога. Полный утверждённый
редакционный список — easy-reviewed.txt. Это редакционная правка, не независимая
методическая экспертиза. Убраны «счёт», «вихрь», «трюм», «клёст» и подобные слова.
Трудные слова перенесены в средний уровень. Добавлены 11 простых слов, которых
не хватало в расширении: всего 1119 слов (69 / 764 / 286 по уровням).

На каждом уровне все посетители получают одни и те же 30 слов в одном порядке
в течение московского календарного дня. При повторном запуске набор тот же.
В 00:00 Europe/Moscow новый запуск получает следующую порцию. Уже начатая
сессия сохраняет свой набор. Соседние дни не повторяют слова. После прохождения
всего словаря слова возвращаются для повторения. Темы и случайность призов
независимы от расписания слов. Дата берётся с устройства; серверного времени нет.

`bank.json` — полный словарь, `new-words.txt` — ровно 1000 добавлений.
`daily-runtime.js` — алгоритм, `daily.js` — собранный браузерный файл без fetch,
работающий также при открытии HTML с диска. При недоступности файла тренажёр
сохраняет работоспособность на прежнем встроенном словаре.

После изменения словаря: `node scripts/build-russian-words.mjs` и
`node --test tests/daily-words.test.mjs`. Перед коммитом:
`node scripts/check-seo.mjs`; после публикации: `node scripts/check-seo.mjs --live`.
Локальная проверка охватывает семь русских публичных страниц: локальный корень
остаётся отдельным неопубликованным прототипом. Live-проверка обходит весь sitemap.
Новые слова и даты не создают отдельные URL или поисковые дубли.
